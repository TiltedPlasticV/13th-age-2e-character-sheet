Go here to load the character sheet:
https://tiltedplasticv.github.io/13th-age-2e-character-sheet/

Alternatively it can be downloaded and run locally — take the whole folder, not
just the HTML file, and open `13th_Age_Character_Sheet.html` from it. The sheet
needs `sheet.css` and `sheet.js` beside it, and the file in `classes/` for the
class you are playing.
